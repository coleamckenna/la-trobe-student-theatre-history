# Contributing to the archive

Each production page is a **curated historical record**, not a comment thread.
Corrections and debate happen on GitHub so changes stay auditable and can be
merged back into the catalogue.

## Edit this page

Production wiki pages are generated from source files under `productions/`.
Use **Edit this page** on any production entry to open the canonical
`production.md` on GitHub and propose a pull request.

Typical pull request changes:

- Fix typos or formatting
- Add or correct dates, venues, and credits
- Add citations in **Notes** or **Materials**
- Link to programs, reviews, or photos hosted elsewhere (see [content notice](content-notice.md))

Do not edit files under `docs/productions/` or `docs/categories/` — they are
regenerated by `python3 scripts/build_wiki.py`.

## Discuss this page

Use **Discuss this page** to open a GitHub Discussion about one production
without editing the record yet. That is the right place for:

- Disputed dates or seasons
- Cast and crew recollections
- Missing production photographs
- Conflicting archival sources
- Oral history from former students and staff

When evidence is clear, someone updates `production.md` via pull request. The
discussion thread remains as provenance.

Repository maintainers should enable **Discussions** and create a category such
as **Historical corrections and contributions** (slug:
`historical-corrections-and-contributions`). Set the slug in [`wiki.toml`](../wiki.toml).

### Pinning a discussion to a page

Pre-filled “new discussion” links are used until a thread exists. To link a
stable thread number, add an entry to `discussions-map.toml` at the repo root:

```toml
["productions/2017/03/the-light-within-a-night-2017/production.md"]
discussion = 42
```

Rebuild the wiki after updating the map.

## Contribute material

Programs, photographs, and scans are generally **not** committed to this
repository because of copyright. Instead:

- Open a [GitHub issue](https://github.com/) describing what you have (with
  your repo URL from `wiki.toml` once configured), or
- Post in the relevant **Discuss this page** thread with links or descriptions
  of where material can be accessed

Maintainers can then cite external holdings in **Materials** or **Notes**.

## Optional: discussions on the page (Giscus)

If you want threads visible under articles later, [Giscus](https://giscus.app/)
can embed GitHub Discussions while keeping the same backend and moderation tools.
Configure it only after Discussions categories exist; it does not replace pull
requests for authoritative catalogue updates.
