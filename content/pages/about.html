About

This project documents the history of student theatre at La Trobe University — productions, people, organisations, venues, and linked archival materials such as program scans.

What this is

  • An open dataset (download {{ sqlite_filename }}) that anyone can query
  • A Datasette catalog for exploring relationships (productions ↔ people ↔ materials)
  • Pretty pages at /{slug} for productions, people, organisations, and venues

Data sources

Production and credit data comes from research into La Trobe student theatre archives. Images and files are not stored in this repository — they are linked to their original hosts.

Scope

The current dataset covers six productions from 1975–1978, with full cast lists and program scans. The schema is designed so additional productions — and eventually other universities — can be added under the same structure.

Catalog data is maintained in git and published as a read-only site.
